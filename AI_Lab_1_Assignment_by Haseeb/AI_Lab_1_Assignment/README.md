# Artificial Intelligence Lab 1
## Introduction to AI & Paradigms

### Files
- `lab1_compare.py`: compares symbolic rules with a probability threshold.
- `lab1_rules.py`: checks four scholarship screening cases.
- `Lab1_Report.docx`: written lab report.
- `outputs/`: captured text outputs from running both programs.

### Requirements
- Python 3.x
- No external Python packages are required.

### Run
```bash
python lab1_compare.py
python lab1_rules.py
```

### Important assumptions
The score threshold (70), probability threshold (0.70), and scholarship conditions in this exercise are synthetic lab assumptions. The program only flags an application for human review; it does not award a scholarship or measure real-world model accuracy.
